# 🎧 Sportify - Spotify Clone

A simple and responsive **Spotify Web Player Clone** built using **HTML, CSS, and JavaScript**.  
This project mimics the basic UI and functionality of Spotify, allowing users to browse and play songs directly in the browser.

---

## 🚀 Features

- 🎵 Play / Pause songs  
- ⏭️ Next / Previous track controls  
- 📃 Dynamic song listing  
- 🎚️ Interactive seekbar (progress bar)  
- 🎧 Real-time song time update  
- 📱 Responsive UI layout  
- 🎨 Clean and modern Spotify-inspired design  

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling & layout  
- **JavaScript (Vanilla JS)** – Functionality

## ⚙️ How It Works

- Songs are loaded dynamically from the `/Songs` folder  
- JavaScript uses the **Audio API** to control playback  
- Event listeners handle user interactions (play, pause, seek, etc.)  
- UI updates in real-time based on song state

## 🧪 How to Run Locally

1. Clone the repository:
   git clone https://github.com/your-username/Sportify-Clone.git

2. Open the project folder
3. Run using a local server (recommended):
   npx live-server
4. Open in browser:
   http://127.0.0.1:8080
